# 窄宽度原生侧栏：Win Group

## 已确认交互

用户确认的入口为原生 Tab 条里、现有分栏按钮左侧的单个叠窗按钮。Hover 展开浮层菜单，内部按 Group 展示已有 docked pane；点击选择整组窗口。不是额外导航行，也不是直接平铺 `1 / 2` segmented buttons。支持点击展开、键盘操作和 Escape，以覆盖触屏及辅助输入。

侧栏双栏在空间不足时仅显示当前组，恢复宽度后回到原双栏布局与比例。组内 Tabs 保持独立，不能合并或关闭文件；保留草稿、滚动和 keepMounted 生命周期。浮窗不算 docked Group。文件从 Files 打开到另一 pane 时，当前显示组应跟随原生资源导航切换。

交互原型（开发侧，不随包发布）：`tmp/design-previews/win-group.html`。

## 职责边界

- **DSH 宿主**：负责按钮、浮层、Group 可见性、自适应测量、焦点、拖拽和 keepMounted/visible 契约。只改变展示，不把临时紧凑模式写回持久化布局。
- **插件**：从 Files 的普通打开行为中定位同会话另一 docked pane，调用原生 `openResource(address, { paneId })`，沿用宿主类型认领与去重。不能因为目标组隐藏而过滤掉该 pane；不通过 CSS 隐藏 pane，也不自行注入原生 Tab 条按钮。
- **没有分栏**：保留原有就地/新标签偏好，不自动建栏。
- **显式右键打开**：保留「在新 Tab 中打开」「在侧边打开」既有语义。

## 插件回归要点

1. 来源栏而非当前焦点决定另一栏（左右对称）。
2. 目标组隐藏/inert 时仍能以 paneId 打开。
3. 不跨会话、不把浮窗当栏、不创建分栏。
4. kept body 拖动后，点击时重新定位 pane。
5. 双栏优先于就地切换，Files 与草稿不被替换。
